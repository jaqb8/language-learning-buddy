# Language Learning Buddy v1.12.0

## What's New

- **Encrypted Learning Data**: Your submitted texts, analysis results, and saved learning items are now protected with server-side encryption at rest, so your personal writing stays private even in our database.
- **Secure Analysis Cache**: Repeated analyses of the same text are stored in encrypted form, keeping cached feedback confidential without slowing down your workflow.
- **No Change to How You Learn**: Encryption runs entirely in the background — the analysis flow, learning list, and account experience work exactly as before.
