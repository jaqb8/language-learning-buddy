# Language Learning Buddy v1.11.0

## What's New

- **English and Polish Interface**: The complete application interface is now available in English and Polish, with English used by default.
- **Application Language Selector**: Switch languages from the header, account menu, or mobile navigation. Your choice is remembered across sessions.
- **Bilingual Text Analysis**: Choose whether the submitted text is written in English or Polish and receive a translation in the other language.
- **Localized AI Explanations**: Error explanations now follow the currently selected application language.

## Fixed

- **Reliable Language Persistence**: Language selections are restored consistently after navigation, page reloads, and authentication.
- **Stable Interactive Controls**: Improved the reliability of analysis inputs, language selectors, and navigation menus while pages initialize.

## Changed

- **Localized User Experience**: Authentication, validation, errors, notifications, settings, gamification, accessibility labels, dates, and page metadata now follow the selected application language.
- **Learning List Language Badges**: Saved learning items show the language of the analyzed text.
- **Streamlined Analysis Options**: Grammar and spelling checks and colloquial speech analysis are available for both supported text languages.
